# ADR-0019: 1.0 API audit — sentinels in backend, internal testutil, exported no-op observers, interface growth policy

**Status:** Accepted
**Date:** 2026-10-21
**Amends:** ADR-0007 (observer), ADR-0011 (pool sentinels), ADR-0015 (conformance imports)
**Issues:** #94, #95, #96

## Context

Before the 1.0 freeze, two independent reviewers audited the exported surface of ten packages (266 identifiers). Findings were merged and each was decided by the owner on 2026-10-21.

| D-2 | Sentinel home | Fix: define `ErrFenced`, `ErrLeaseHeld`, `ErrLeaseExpired`, `ErrInvalidExitMode` in `backend`; re-export from `worklease` as the same values with the same messages (#95) | no |

## Placement

| Item | Defined in | Exposed by package worklease as |
|---|---|---|
| `SweepOptions` | `backend` | type alias |
| `ExitMode`, `Checkpoint` | `backend` (ADR-0018) | type aliases |
| `ExitNone`, `ExitFinished`, `ExitAbandoned`, `ExitRetired`, `ExitExpired` | `backend` | constants equal to the backend constants |
| `ErrFenced`, `ErrLeaseHeld`, `ErrLeaseExpired`, `ErrInvalidExitMode` | `backend` | variables equal to the backend variables, so `errors.Is` matches either name |
| `ErrLeaseWindowExhausted`, `ErrConfigInvalid`, `ErrNilBackend`, `ErrRetire`, `ErrRetentionRequired` | `worklease` | defined there; backends do not return them |

Application code uses the package worklease names; backend implementers use the package backend names.

## Consequences

No non-test file in a backend package imports package worklease, so package worklease can import a backend package in a later release without an import cycle. Three changes break callers: testutil is internal, pool.ErrNilLease is pool.ErrLeaseRequired, and Operation values start at 1. Rejected items (postgres.New options, constructor shapes, WorkFn signatures, leader callbacks, HasWaitForLease) are not reopened before 1.0 without new evidence. Known limitation, not scheduled: pool.New does not validate its work function, so a nil work function passes New (D-17).
